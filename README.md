# Kharcha Journal – Frontend

Frontend for **Kharcha Journal**, a personal finance web application for tracking expenses, categories, daily journals, dashboards, analytics, and date-range reports.

## 🚀 Live Application

https://kharcha-frontend.pages.dev/login/

## ✨ Features

- Expense tracking
- Expense categories
- Daily journal
- Dashboard and analytics
- Date-range reports
- CSV, Excel, and HTML export
- Authentication
- Responsive UI
- Installable PWA
- Kharcha Assistant integration

## 🛠️ Tech Stack

- Next.js 15
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- React Query
- Zustand
- Recharts

## ☁️ Deployment

The frontend is deployed on **Cloudflare Pages**.

The application communicates with the Kharcha Journal API running on Cloudflare Workers.
